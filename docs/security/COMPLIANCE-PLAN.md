# برنامهٔ انطباق با الزامات واحد معماری امن

این سند الزامات نامهٔ واحد معماری امن را به فازهای اجرایی تقسیم می‌کند و وضعیت هر فاز را نگه می‌دارد.
هر فاز جداگانه پیاده، تست و روی شاخهٔ `security/compliance` کامیت می‌شود.

> **توجه:** عنوان نامه «سامانهٔ مسابقهٔ dotinschool-game» است. این مخزن سامانهٔ **چالش برنامه‌نویسی** (dotinschool-challenge) است.
> مواردی که فقط به بازی مربوط‌اند (Endpoint `api/game/replay`، `testMode`، مدیریت بانک سؤال) در این مخزن وجود ندارند و باید در مخزن `dotinschool-game` اعمال شوند.

## فاز ۱ — آنچه انجام شد

جزئیات و پیکربندی: [TLS-POLICY.md](TLS-POLICY.md)

- **حالت عملیاتی (`APP_ENV=production`)**: برنامه بدون TLS اجرا نمی‌شود (یا گواهی مستقیم، یا `TLS_PROXY=1` پشت پروکسی). اگر مسیر گواهی تنظیم شده ولی فایل نباشد، دیگر بی‌صدا به HTTP برنمی‌گردد و اجرا متوقف می‌شود. هر درخواست غیر TLS با `403 TLS_REQUIRED` رد می‌شود. دادهٔ نمایشی (شرکت‌کنندهٔ ساختگی) در این حالت ساخته نمی‌شود.
- **پنل مدیریت فقط روی TLS، در همهٔ حالت‌ها**: ورود و تمام APIهای اداری روی HTTP ساده رد می‌شوند (به‌جز اتصال محلی loopback بدون هدر پروکسی، مثل SSH tunnel). کلید توسعه‌ای `ALLOW_INSECURE_ADMIN` در حالت عملیاتی مانع اجرا می‌شود.
- **محدودیت شبکه‌ای پنل (`ADMIN_ALLOWED_CIDRS`)**: خارج از این شبکه‌ها، صفحهٔ پنل، ورود و همهٔ APIهای اداری — حتی با توکن معتبر — پاسخ `404` می‌دهند و تلاش در لاگ ثبت می‌شود. در حالت عملیاتی اجباری است (`any` فقط وقتی لبه آن را اعمال می‌کند).
- **TLS 1.2+ با Cipherهای قوی** در برنامه و همهٔ Caddyfileها (فقط ECDHE + AEAD).
- **HSTS یک‌ساله با includeSubDomains** در هر حالت TLS (مستقیم یا پشت پروکسی معتبر).
- **IP واقعی از یک منبع واحد**: فقط یک هدر (`CLIENT_IP_HEADER`) و فقط از پروکسی معتبر پذیرفته می‌شود. در Docker، به‌جای کل بازهٔ خصوصی، فقط IP ثابت Caddy روی یک شبکهٔ اختصاصی با subnet مشخص معتبر است.
- **پورت برنامه در Docker عملیاتی** فقط روی loopback میزبان منتشر می‌شود؛ دسترسی عمومی فقط از Caddy.
- **Timeout**: سرور (هدر ۱۰ث، خواندن ۳۰ث، نوشتن ۱۲۰ث، بیکاری ۶۰ث، سقف هدر ۶۴KB؛ فقط مسیرهای انتقال حجیم ۱۰ دقیقه) و کلاینت (هر درخواست فرانت ۳۰ث، هوش مصنوعی ۱۲۰ث).
- **تست خودکار** که هر مسیر API غیرعمومیِ جدید را بدون `requireAdmin` شکست می‌دهد (بند ۴.۳).
